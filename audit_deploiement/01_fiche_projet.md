# 01_fiche_projet.md

## Nom du projet
RecrutPlus

## Objectif
Application de recrutement permettant aux candidats de postuler, suivre leurs candidatures et entretiens, et aux RH de gérer le processus de recrutement.

## Technologies
- Backend : Java / Spring Boot
- Frontend : React / TypeScript
- Base de données : MySQL - MongoDB
- Auth : JWT
- Mails : Ethereal en dev
- Stockage CV : MongoDB / GridFS
- Tests : JUnit 5, Mockito

## État d'avancement
Fonctionnel en local. Non déployé.

Oui — React/TypeScript

## Présence d'un back
Oui — Spring Boot (API REST)

## Bases de données
Oui — MySQL - MongoDB
